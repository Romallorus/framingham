# framingham
В данном репозитории собрано веб-приложение для проверки ишемической болезни у пациентов. Приложение требует формат входных данных в формате csv файла, также можно проверить отдельно одного пациента по его данным. Перед применением советую ознакомиться со справкой показателей, которые указываются у пациента.
